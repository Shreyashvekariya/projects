# Customer Churn Analysis

## Overview

This repository folder contains a Customer Churn Analysis project. The objective is to explore customer data, build models to predict churn, and provide insights and recommendations to reduce churn.

## Contents

- data/: raw and processed datasets (not included here)
- notebooks/: exploratory data analysis and modeling notebooks
- src/: data processing and modeling scripts
- reports/: figures, model evaluation results, and final report

## Goals

- Understand drivers of customer churn
- Build baseline and advanced predictive models
- Evaluate model performance and interpret key features
- Provide actionable recommendations to reduce churn

## How to use

1. Clone the repository:

   git clone https://github.com/Shreyashvekariya/projects.git

2. Change to the folder:

   cd "Customer Churn Analysis"

3. Follow notebooks in `notebooks/` and scripts in `src/` to reproduce analysis.

## Environment

- Python 3.8+
- pandas, numpy, scikit-learn, matplotlib, seaborn, jupyter
