# E-Commerce Sales Analysis (Excel + Power BI)

This folder contains files and documentation for the E-Commerce Sales Analysis project using Excel and Power BI.

Planned contents:
- Excel workbooks with raw and cleaned data, pivot tables, and supporting calculations
- Power BI report (.pbix) with interactive dashboards
- Data preparation scripts or documentation

Current status:
- README created to initialize the folder

How to contribute:
1. Add Excel files and Power BI report files to this folder.
2. Commit clear filenames and a brief README for each added file describing its purpose.
3. If you add large binary files (e.g., .pbix), consider using Git LFS.
